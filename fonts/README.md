| Role | Face | Get it |
| --- | --- | --- |
| Display and long reading | Source Serif 4, 600 for headings, 400 for text | [Source Serif 4](https://fonts.google.com/specimen/Source+Serif+4) |
| Interface | IBM Plex Sans, 400 and 500 | [IBM Plex Sans](https://fonts.google.com/specimen/IBM+Plex+Sans) |
| Code, terminal, data | IBM Plex Mono, 400 and 500 | [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) |
| Logo drawing only | Big Shoulders Display Black | [Big Shoulders Display](https://fonts.google.com/specimen/Big+Shoulders+Display) |

IBM Plex Mono Medium is also outlined into the stamps and tape (`data/IBMPlexMono-Medium.woff2`).

The logos are drawings, not typed text, so they need none of these at use time. `src/animal_spirits_brand/data/BigShouldersDisplay-Black.woff2` is the copy the wordmark is outlined from; do not use Big Shoulders for anything else.
